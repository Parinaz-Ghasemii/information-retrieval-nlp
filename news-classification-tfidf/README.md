# Information Retrieval and NLP projects

Projects from a university Information Retrieval course (University of Tehran), implemented in Python. Each folder is self-contained, with its own README, results and instructions to run it.

| Project | Topic | Highlights |
|---|---|---|
| [`news-classification-tfidf`](news-classification-tfidf) | Text classification | TF-IDF implemented from scratch, LinearSVC and Logistic Regression, 97.4 % macro-F1 on a five-class news dataset |

The datasets are not included in this repository; each project's README says what to download and where to put it.
